# 婚禮網站改版

## 已確認範圍

- 婚禮前台視覺、賓客導覽、出席表單與確認頁、草稿、錯誤與無障礙操作。
- 電話格式、同名查詢、主餐數量、公開資料與回覆修改驗證、靜態路徑保護。
- 後台設定草稿與載入狀態、相簿、圖片與字型效能。
- 座位圖：可收合資訊卡、入口選擇、BFS 繞障礙路線、後台障礙物與通行設定。

- 使用者後續要求移除全部 3D 功能；Three.js、模型、建模腳本與前後台 3D 入口已移除，原始製作紀錄可在 Git 歷史中取得。
- 喜帖信封開場、捲動故事與相簿預覽、依開放階段變化的回訪首頁。

## 執行紀錄

- 已檢查現有程式、正式站登入預覽與手機尺寸座位頁。
- 開發與驗證使用本機隔離資料庫，不寫入正式賓客資料。
- 已完成婚禮首頁、精簡賓客頁首、底部導覽、當天流程與交通資訊。
- 送出後顯示人數、餐點收據、行事曆、地圖與專屬回覆連結；同分頁草稿保留 24 小時，送出即清除。
- 餐點修改需 Email 一次性驗證碼或有效回覆連結；登入後台仍可直接預覽。驗證碼 10 分鐘、最多試 5 次；修改驗證有效 30 分鐘、收據連結 90 天。
- 新舊電話格式統一；同名賓客需補手機。主餐必須等於大人人數；不回傳後台備註和兒童計價設定。
- BFS 避開桌椅、牆、柱與禁止區域，支援多入口、可調通行緩衝、連通性檢查與路線平滑。
- 查詢成功先標出「我的位置」，停留 1.1 秒，再以 1.1 秒平滑放大到完整路線；觸控、滾輪或按鍵立即中斷，減少動態效果設定會直接呈現路線。
- 後台新增牆、柱、禁止通行區域與美福尺寸比例；不自動改動既有桌椅配置。
- 首頁兩張 WebP 合計 84,784 bytes，原 PNG 合計 2,828,619 bytes，減少約 97%。原圖保留。
- 修正設定頁儲存其他區塊時覆蓋未儲存文案、設定及婚宴費用載入錯誤消失、表單標籤、鍵盤下拉、相簿錯誤重試與燈箱焦點。
- 前端更新 Vite 7、React Router 7 與 Quill 2；RichTextEditor 進出 HTML 均經 DOMPurify 淨化。
- 首次首頁提供封蠟拆信動畫，可略過、按 Escape 關閉或重播，鍵盤焦點留在喜帖內並於關閉後恢復。回訪直接在頁首呈現倒數及目前開放的餐點／座位入口；開放階段有變化時提示新消息。
- 故事採用 2019/04/29 在一起、預計 2027/01/26 登記、2027/03/13 婚宴三個日期；相簿預覽沿用公開開關與登入權限，接近畫面才載入。使用者會另行提供照片；手機直式與網站橫式敘事影片尚待素材，未使用 Google Photos 私人照片作為公開資源。
- 倒數採台灣時間，背景分頁暫停計時；捲動照片離開畫面即停止更新，節省流量模式停用視差。減少動態效果設定會立即呈現內容；封鎖瀏覽器儲存時仍可讀取公開資訊。

## 操作與驗證

後台「座位圖」→「預覽座位與路線」可開啟全螢幕平面地圖；選桌或座位，展開下方資訊可選入口。尋路不提供即時定位，從賓客選定的入口開始；通道不連通時不提供穿牆路線。

`畫布` 中可選「套用美福 38 × 20 公尺比例」，此時每 50 單位約 1 公尺。桌椅與入口需按現場位置配置；此選項不會重新排列既有物件。

```powershell
# 前端：Node 22.13+ 或 24 LTS
cd frontend
npm ci
npm run lint
npm test
npm run build
cd ..
# 後端：Python 3.10+
backend/.venv/Scripts/python.exe -m pip install -r backend/requirements-dev.txt
cd backend
.venv/Scripts/python.exe -m pytest tests -q
cd ..
# 獨立本機預覽；臨時 SQLite、虛構名單、關閉所有寄信與通知
backend/.venv/Scripts/python.exe scripts/preview_local.py
```

預覽網址 `http://127.0.0.1:8010/admin`，密碼 `preview-wedding-only`，測試桌次輸入 `0912345678`。所有開關預設關閉，需先登入 admin 才能預覽；此資料與正式站完全分離。

已完成後端 8 項隔離整合測試、前端 9 項尋路與電話測試、ESLint 與 production build。已實測本機 admin 登入、手機 390 × 844 桌次頁、BFS 路線、主餐不足阻擋及送出收據／草稿清除。開場動畫依序呈現位置、放大、路線，手動操作可中斷；關閉地圖恢復頁面焦點。鍵盤選單、出席草稿重新整理恢復，以及設定頁跨區塊儲存保留文案均已實測。

首頁更新後，前端共 13 項測試通過（新增倒數時區邊界、開放階段與回訪儲存測試），ESLint 與 production build 通過。`scripts/qa_home.py` 使用獨立無頭 Edge、隔離預覽資料與瀏覽器攔截的相簿素材，驗證首次拆信、略過／重播、焦點恢復、回訪入口、320／390／768／1440px 寬度、故事進場、相簿關閉時不請求、admin 登入與圖片驗證、照片燈箱、減少動態效果及儲存停用。未操作使用者的 Edge 設定檔。

執行互動回歸需在本機測試 Python 環境安裝 `playwright`，並已安裝 Edge；先開啟上述隔離預覽，再執行 `backend/.venv/Scripts/python.exe scripts/qa_home.py`。此套件不屬於正式部署依賴。截圖寫入系統暫存資料夾，路徑在測試結束時印出。
