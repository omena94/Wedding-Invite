# 大螢幕版面清單（200 個）

新人要求：版面要多（兩百個），不要整晚都是字；要有兩個人（和芃芃、QQ）打球、互動的手繪動畫。
每個版面都是 `src/wall/scenes/<名字>.ts`，自己 `export const spec` 宣告排程參數（見 ENGINE.md）；
**每個都要跑過 `qa` 並打開總表與全尺寸截圖檢查**才算完成。

- **group**：`couple` = 手繪新人／狗狗互動（用 `scenes/_couple.ts`），`type` = 文字／圖像版面。導演會讓兩類交替。
- **family**：系列，同系列不會連著出現。
- 亮 = 紙底（`paper: true`，回傳 `paper: 1`）；暗 = 深色底。
- 每個版面都要照 TREATMENT.md 的跟唱規則與留言規則：歌詞逐字跟唱、留言讀得完、沒有留言／沒有歌詞也成立。
- 下面的點子是方向，不是規格：畫得出來、讀得到、跟著節拍動、好看最重要。可以改細節，但名字（檔名）不要改。
