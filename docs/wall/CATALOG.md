# 大螢幕版面清單（200 個）

新人要求：版面要多（兩百個）、更多元；舊的版面保留；一部分場景要有兩個人（和芃芃、QQ）打球、互動的手繪動畫。
每個版面都是 `src/wall/scenes/<名字>.ts`，自己 `export const spec` 宣告排程參數（見 ENGINE.md）；
**每個都要跑過 `qa` 並打開總表與全尺寸截圖檢查**才算完成。

- **group**：`couple` = 新人／狗狗互動（紙偶動畫 `scenes/_puppet.ts`，是點綴），`type` = 文字／圖像版面（大部分）。
- **family**：系列，同系列不會連著出現。
- 亮 = 紙底（`paper: true`，回傳 `paper: 1`）；暗 = 深色底。
- 每個版面都要照 TREATMENT.md 的跟唱規則與留言規則：歌詞逐字跟唱、留言讀得完、沒有留言／沒有歌詞也成立。
- 下面的點子是方向，不是規格：畫得出來、讀得到、跟著節拍動、好看最重要。可以改細節，但名字（檔名）不要改。

## 照片版面（photo: true）

新人在後台打開「照片與註解」時，導演會排「照片窗格」：`params.photo` 是一張新人選的照片（婚紗照、成長照、手機照，橫的直的、很大很小都有）與註解；
照片窗格也是 MV：主字是賓客留言（`params.message`，有註解的照片一輪放註解、一輪放留言）或註解，歌詞在下面跟唱，鏡頭往新人點的焦點推；
一次放好幾張的版面（`spec.photos`）另外拿 `params.photos`。一般窗格不會排到這些版面。導演依接下來的照片種類（`spec.prefers`）、亮暗、系列（`spec.series`，同系列不連著）挑版面。
規則與檢查方法見 ENGINE.md「照片版面」；驗收跑 `qa`（照片版面自動換成照片的情境）。分批的計畫見 PHOTO_PLATES.md。
